# סלייד־א־לאמה 🏛️

שחזור מלא של **Slide-A-Lama** — משחק הלאמות האגדי שהגיע עם ICQ ב־2004 — כמשחק דפדפן סטטי.
HTML, CSS ו־JavaScript בלבד: בלי ספריות, בלי שלב בנייה, בלי קבצי תמונה או שמע.
כל הגרפיקה היא SVG שנוצר בקוד, וכל הצלילים מסונתזים ב־Web Audio API.

**לשחק עכשיו:** https://israelb014.github.io/slideAclaude/

---

## החוקים

המשחק הוא דו־קרב תורי לשני שחקנים על לוח 5×5 ("המקדש"). הלוח מתחיל ריק.

### תור

בכל תור השחקן מקבל אריח אחד (מוצג במשבצת "האריח הבא") וחייב להחליק אותו ללוח
דרך אחת מ־**15 נקודות הכניסה**: חמישה טורים מלמעלה, חמש שורות משמאל, וחמש שורות מימין.

### פיזיקת ההחלקה

| כיוון | מה קורה | כשהנתיב מלא |
|---|---|---|
| **מלמעלה** | האריח נופל בטור ונערם על האריחים הקיימים | האריח **התחתון נמחץ**, הטור יורד, והחדש נוחת למעלה |
| **משמאל** | האריח דוחף את כל השורה ימינה | האריח **הימני ביותר נדחף החוצה** ונהרס |
| **מימין** | האריח דוחף את כל השורה שמאלה | האריח **השמאלי ביותר נדחף החוצה** ונהרס |

אחרי כל דחיפה אופקית מופעלת **כבידה**: אריחים שמעליהם חלל נופלים מטה עד שהלוח יציב.
רק אז נבדקות ההתאמות.

### התאמות, כפולות וקומבו

שלושה אריחים זהים או יותר ברצף ישר — אופקי או אנכי — מתפוצצים ונזקפים לזכות השחקן שביצע את המהלך.

* **רצף 3** — ערך האריחים ×1
* **רצף 4** — ערך האריחים ×1.5
* **רצף 5+** — ערך האריחים ×2

אחרי הפיצוץ מופעלת כבידה שוב. אם נוצרו התאמות חדשות — אלו **קסקדות**, והן שוות
כפול: הקסקדה הראשונה ×1, השנייה ×2, השלישית ×3 וכן הלאה, עד שהלוח יציב.
כל הקסקדות נזקפות לזכות אותו שחקן.

### האריחים

| אריח | ניקוד | נדירות |
|---|---|---|
| בננה | 10 | 30 |
| דובדבן | 15 | 25 |
| תפוח | 20 | 20 |
| ענבים | 25 | 15 |
| פעמון זהב | 40 | 7 |
| יהלום | 60 | 3 |

האריחים מוגרלים במשקל הפוך לערכם — בננות נפוצות, יהלומים נדירים.

### הלאמות — תנאי הניצחון

עשר לאמות יושבות על הספסל שמעל לוחות הניקוד. בתחילת המשחק חמש פונות לכל צד.

על כל **60 נקודות יתרון** מלא לשחקן אחד, לאמה אחת חוצה לצד שלו. אם היתרון מצטמצם —
הלאמות חוזרות. הנוסחה המדויקת:

```js
lamasForP1 = clamp(5 + floor((scoreP1 - scoreP2) / 60), 0, 10)
```

**מי שאוסף את כל עשר הלאמות לצדו — מנצח מיד.**

רשת ביטחון: אם עברו 200 תורות ואיש לא הכריע, מנצח בעל הניקוד הגבוה יותר (ובניקוד זהה — תיקו).

## מצבי משחק

* **נגד המחשב** — בשלוש רמות קושי:
  * *קל* — מהלך אקראי חוקי.
  * *בינוני* — מדמה את כל 15 המהלכים ובוחר את בעל הרווח המיידי הגבוה ביותר, עם מעט אקראיות.
  * *קשה* — מדמה את כל 15 המהלכים כולל קסקדות, ומדרג כל מהלך לפי
    `(הרווח שלי − התשובה הטובה ביותר של היריב × 0.7)` בעומק מהלך אחד קדימה.
* **שני שחקנים** — על אותו מכשיר, בתורות, עם חיווי ברור של מי משחק כרגע.

## הפעלה

אין שלב בנייה. אפשר פשוט לפתוח את `index.html` בדפדפן.
להרצה דרך שרת מקומי (נדרש כדי לבדוק את ה־Service Worker):

```bash
npx http-server -p 8080 .
# ואז http://localhost:8080
```

### בדיקות

`tests.html` מריץ 22 בדיקות על לוגיקת המשחק הטהורה — פיזיקת הכנסה משלושת הכיוונים,
דחיפה החוצה משורה מלאה, מחיצת אריח בטור מלא, כבידה, זיהוי רצפים, מכפילי אורך,
קסקדות, חישוב הלאמות ותנאי הניצחון. פותחים את הקובץ בדפדפן; התוצאות מוצגות בעמוד וגם בקונסולה.

### PWA

`manifest.json` ו־`sw.js` הופכים את המשחק לאפליקציה שניתן להתקין ולשחק בה גם בלי חיבור לרשת.
האייקונים מוטמעים כ־data-URI, כך שאין בפרויקט אף קובץ תמונה.

## מבנה הפרויקט

```
index.html          שלד הדף וארבעה מסכים: פתיחה, תפריט, משחק, סיום
tests.html          בדיקות ללוגיקה הטהורה
css/style.css       כל העיצוב — מקדש אנדי בשקיעה, ללא גופנים או תמונות חיצוניים
js/game.js          מנוע החוקים. לוגיקה טהורה בלבד — אין בו שום גישה ל־DOM
js/ai.js            היריב הממוחשב. עובד על עותקי לוח קלים, לא נוגע בתצוגה
js/audio.js         סינתזת כל הצלילים ב־Web Audio API
js/ui.js            רינדור, קלט ואנימציות. הצד היחיד שמכיר את ה־DOM
manifest.json       הגדרות PWA (אייקונים מוטמעים כ־data-URI)
sw.js               Service Worker — קאשינג מלא לשימוש לא־מקוון
```

ההפרדה בין `game.js` ל־`ui.js` היא הכלל המרכזי בפרויקט: מנוע החוקים מחזיר
מצב לוח ו"יומן צעדים", והתצוגה רק מציירת אותו. זה מה שמאפשר לבדוק את כל
הלוגיקה בלי דפדפן ולתת ל־AI לדמות מאות מהלכים בלי לגעת במסך.
